## Gotchas
- `codex app-server` speaks newline-delimited JSON-RPC over stdio; assigning it
  directly to `ANTHROPIC_BASE_URL` cannot work.
- Tool fidelity is the hard part: the bridge must translate tool definitions,
  tool calls/results, streaming, cancellation, and concurrent request identity.
- Do not copy Hermes' Codex CLI originator headers or share/import rotating OAuth
  token caches. Let the installed Codex CLI own credentials and refresh.
- Local `origin/main` was stale during this session; fetch before branching.
- `.codex/config.toml` is untracked and user-owned. Do not stage or modify it.
